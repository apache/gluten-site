Download Apache Gluten

Instructions

Select a version of Gluten to download from the list below. We recommend downloading the latest release.

Ensure the integrity of the release by verifying the corresponding SHA-512 hashes and signatures with the project release KEYS.

You can find verification instructions in the provided guide.

The Latest Official Releases

Please note that the binary files were compiled on CentOS 7 using static linking. Starting with the 1.5.0 release, the Intel® Xeon® Platinum 8272CL or a similar CPU variant is used (as determined by GitHub for the ubuntu-latest runner). For earlier releases, the Intel® Xeon® Gold 6252 CPU was used. Performance and runtime compatibility are not guaranteed on other operating systems or hardware platforms. For optimal performance and maximum platform compatibility, we recommend compiling the source code yourself.
